# Bank-AnalyticsProject
End-to-end bank analytics project with dashboards for Loan Analysis 
and Credit & Debit Transaction Analysis built using Excel, Power BI, Tableau, and SQL.

## Project Overview
A comprehensive bank analytics project that transforms raw financial data 
into actionable business insights through two interactive dashboards — 
Bank Loan Analytics and Credit & Debit Transaction Analysis.

## Dashboards Built
### 1. Bank Loan Analytics Dashboard
- Tracks total loan disbursement, collections, and interest income
- Monitors default rate and delinquency rate for credit risk assessment
- Breakdown by branch, state, loan grade, age group, and loan purpose
- Yearly disbursement trend and loan term (maturity) distribution

### 2. Credit & Debit Transaction Dashboard
- Analyses total credit vs debit flow across all bank branches
- Calculates Credit-to-Debit Ratio and Net Transaction Amount
- Transaction trends by day, week, and month
- Branch-wise transaction volume and account activity ratio

- ## Key KPIs Tracked
- Total Loan Funded | Total Collections | Total Interest Income
- Default Rate % | Delinquency Rate %
- Total Credit Amount | Total Debit Amount
- Credit-to-Debit Ratio | Net Transaction Amount

## Business Impact
This project enables a bank to:
- Identify high-risk branches with elevated default and delinquency rates
- Monitor cash flow health through credit vs debit trends
- Make data-driven decisions on loan approvals and branch performance
